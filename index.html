Signet

A personal mark for documents you've read. Register once, then produce a short code that ties you, and only you, to a document and date — without ever exposing your password.

Register your function and choose a password. Only a one-way derivative of your password is produced — never the password itself. Do this once, or again if you want to change your password.

Enter your function and password, the date, and a short reference for the document (its filename, an ID, or a distinctive phrase). You'll get a 6-character code plus a copy-ready block to put on the document.

Enter the code found on a document, along with its date and reference. Signet will check it against every registered function and tell you who it belongs to.

Registered functions are looked up from registry.json, a plain file shipped with this site, plus anything registered on this device. Passwords are never stored or transmitted — only a one-way derivative used to check codes. See the project's README for how to add new people to the shared registry.
